# Scripts

This directory is reserved for small, documented utilities supporting Noctua development and testing.

**Current status:** No tested project script is published here yet.

When adding a script, document:
- What it does and why it exists
- Required Python version and dependencies
- Required configuration, without credentials
- An example command with safe placeholder values
- Expected output and known limitations
- How the script was tested

Do not claim continuous recording, reconnection or monitoring until the corresponding script and tests exist.
