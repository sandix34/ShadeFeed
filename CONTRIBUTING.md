# Contributing to Noctua

## Project Philosophy

Noctua is an independent wildlife monitoring project combining field expertise, embedded systems, networking, and software development.

The project is developed through a **human-led, AI-assisted approach**, where practical experimentation, continuous learning, and technical validation guide development.

Artificial intelligence is integrated into the development workflow as a permanent technical collaborator.

## Human Expertise and Project Ownership

The project owner is responsible for:

- Defining wildlife monitoring objectives and field requirements.
- Selecting and evaluating hardware components.
- Identifying environmental and deployment constraints.
- Designing practical field integration strategies.
- Performing hardware and software testing.
- Evaluating results and making final technical decisions.
- Maintaining the project and developing the necessary technical skills.

Field expertise plays a central role in shaping the system's architecture and operational requirements.

## AI Collaboration

ChatGPT (OpenAI) contributes throughout the development process by assisting with:

- Software development and debugging.
- System architecture and networking.
- Hardware and software integration.
- Technical research and problem-solving.
- Documentation and code review.
- Learning and understanding new technologies.

AI-generated solutions are not automatically considered validated. Their reliability must be established through appropriate testing and practical evaluation.

## Development Workflow

Development follows an iterative approach:

1. Identify a technical or field requirement.
2. Explore potential solutions through human–AI collaboration.
3. Implement and document the selected approach.
4. Test and evaluate the results.
5. Refine the implementation based on observed behavior.

Failures, limitations, and technical decisions are part of the learning process and should be documented whenever relevant.

## Version Control and Transparency

Git is used to maintain a traceable history of the project's development.

Commit messages describe technical changes using conventional prefixes such as `feat`, `fix`, `docs`, `test`, and `refactor`.

Because AI assistance is an integral part of the project's regular workflow, individual commits do not systematically identify AI involvement.

This document provides project-level transparency regarding the development methodology.

## Guiding Principle

**AI supports implementation and learning. Human expertise defines the purpose, evaluates the results, and retains responsibility for the project.**
